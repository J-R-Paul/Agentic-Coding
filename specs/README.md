# Specifications for bounded work items

Create one subfolder per scoped work item. The spec skill writes a draft spec.md within that folder and stops for your review. Only you can approve the research design. Request implementation separately after checking the draft.

A work item should have one independently checkable deliverable. Keep the overall commission and the list of upcoming items in a project overview or roadmap, rather than expanding one spec to cover the entire project. The starter has no completed student specifications.
