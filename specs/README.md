# Specs

The `spec-driven-research` skill writes here (card 06):

- `mission.md`, `tech-stack.md`, `roadmap.md`, `log.md`: one copy each, for the whole project.
- One folder per task, `YYYY-MM-DD-short-name/`, holding `requirements.md`, `plan.md`, `validation.md` and `decisions.md`.

A new chat can pick up the project from these files alone.
