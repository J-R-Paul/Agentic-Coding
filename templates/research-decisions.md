# My decisions for one research work item

Write in your own words before using the spec skill. It is acceptable to write `unresolved`; the agent should ask about the consequential gaps. This worksheet is not an approved spec.

1. What single deliverable do I want to complete and check?

2. What question will it answer, and what claim do I intend to make?

3. Which observations should enter, and why? State the unit of observation.

4. What does each measure mean? Give its source column, any transformation, and its units.

5. What model or comparison do I intend to use? State the variables and why they belong. Which uncertainty calculation do I want reported?

6. How should special codes, genuine zero values, conditional variables and incomplete observations be treated?

7. What files will count as the completed deliverable?

8. What check would distinguish a meaningful result from a script that merely runs?

9. What remains unresolved? Ask the agent for an explanation if needed; you retain the choice.
