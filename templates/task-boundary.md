# Bounded task card

## Intended output
Name the one file or result you want, and what it should contain.

## Inputs and meaning
Name the exact data and documentation. State the population, units and any research decisions already made.

## Allowed changes
Name the files or folders the agent may create or edit.

## Things to inspect
Write two observable checks you will perform yourself. Include one check of meaning, such as units, sample coverage, missing codes or interpretation.

## Stop condition
State when the agent should stop and what it should report. Add an explicit boundary if you want inspection only before edits.
